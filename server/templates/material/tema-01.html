Tema 1

Variables y tipos de datos

Cómo guarda la información un programa.

Objetivos

Declarar variables
Distinguir tipos de datos
Convertir entre tipos

Ejemplo

const nombre = "Ana"      // texto (string)
let edad = 28             // número (number)
const activa = true       // lógico (boolean)

Ejercicio 1

Declara una variable con tu ciudad y otra con el año actual. ¿De qué tipo es cada una?

Pregunta 1

¿Qué tipo de dato es "42"?
