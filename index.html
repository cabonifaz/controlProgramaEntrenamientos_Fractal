Módulos del programa

Ocho áreas que cubren el ciclo completo de un producto: desde cómo versionas el código hasta cómo lo despliegas, lo aseguras y lo potencias con IA.

Versionamiento de código

Trabaja con Git como en un equipo real: ramas, flujo de cambios y publicación automatizada.

  • Ramas y estrategias de trabajo
  • Operaciones: push, pull, merge
  • Publicaciones: CI/CD y Pages

Arquitectura

Diseña y despliega en la nube con criterios de seguridad desde el primer día.

  • AWS: S3, EC2, Lambda, CloudFront, VPC
  • Railway
  • Unix y motores: MySQL, SQL Express
  • Seguridad: firewall, claves SA, puertos

Análisis de funcionalidades

Del requerimiento al diseño funcional: roles, secuencias y control de errores.

  • Multirol
  • Funcionalidades generales
  • Maestro de maestros
  • Granularidad y desacoplamiento
  • Secuencias funcionales y happy paths
  • Validaciones y control de errores

Base de datos

Modela, optimiza y aplica en la práctica, tanto en SQL como en NoSQL.

  • SQL: optimización y stored procedures
  • Maestro de maestros
  • MongoDB
  • Aplicación práctica

Vibe Coding

Programa con IA de forma efectiva y sin perder el control del código.

  • Prompt óptimo
  • Prompt para soporte
  • Full control
  • Vibe mobile

IA funcional aplicada

Integra IA al producto: OCR e interpretación de datos para casos reales.

  • OCR
  • Interpretación de imágenes
  • Prompt funcional
  • Interpretación y XML / JSON

Backend

Construye servicios y microservicios con foco en la experiencia de uso.

  • C#
  • Java
  • Microservicios
  • Desarrollo de servicios y experiencia

Frontend

Interfaces con microfrontends y desarrollo seguro de punta a punta.

  • Angular (microfront)

  • Desarrollo seguro
  • OWASP
